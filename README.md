# 雀会

## サイト概要
### サイトテーマ
麻雀を一緒に打つ仲間を見つける、コミュニティサイト

### テーマを選んだ理由
私は友人と麻雀を打っていましたが、その友人が遠方へ引っ越して
しまい、それ以来、一緒に麻雀を打つ機会が減ってしまいました。
麻雀は複数人が揃わないと遊べないため、身近に一緒に打てる
仲間がいなくなると、続けることが難しくなります。同じように、
環境の変化などをきっかけに、麻雀を一緒に打つ相手がいなくなって
しまった人は少なくないのではないかと考えました。

この課題を解決するために、麻雀好きが集まり、新しい仲間と
一緒に打つ機会を作れるコミュニティサイトを制作しようと考えました。

### ターゲットユーザ
- 対面で麻雀を打ちたい人
- 新しい麻雀仲間を探している人

### 主な利用シーン
- 休日に暇な時
- 定期的に麻雀を打つ仲間を見つけたい時
